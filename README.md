# Eventure

**Plataforma fullstack para la gestión de eventos, con integración de API y diseño responsivo.**

## 🚀 Descripción

Eventure es una solución moderna y eficaz para organizar y asistir a eventos. Ofrece una interfaz intuitiva para la creación, exploración y gestión de eventos, optimizando la planificación tanto para organizadores como para participantes.

## ✨ Características

- 📅 **Gestión de eventos**: Crea, edita y elimina eventos fácilmente.
- 🔎 **Búsqueda y filtrado**: Encuentra eventos por nombre o categoría.
- 💳 **Reservas**: Página de reservas para eventos disponibles.
- 🔐 **Autenticación**: Integración con Clerk para login y control de usuarios.
- 📱 **Responsive**: Diseño adaptado a móviles, tabletas y escritorio.
- ⚙️ **Integración con API**: Comunicación eficiente entre frontend y backend.

## 🛠️ Tecnologías utilizadas

- **Next.js 13** (App Router)
- **React** & **TypeScript**
- **Tailwind CSS**
- **MongoDB** (Mongoose)
- **Clerk** (para autenticación)
- **Cloudinary** (para carga y manejo de imágenes)
- **Shadcn/UI** (componentes de interfaz)
- **React Icons**
